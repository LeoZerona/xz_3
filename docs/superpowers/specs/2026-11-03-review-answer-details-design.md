# 复习作答后的详情与更正

用户需要在选择认识或不认识后核对文字，并更正误点。关卡复习与复习中心的每日课程复习均采用：辨认字形 → 选择答案 → 查看当前文字完整详情 → 手动下一字。

复用 CharacterDetailContent 展示学习字体、对照字体、拼音、释义、常用词、结构和说文内容。沿用已有主题与 uni-app scroll-view；关卡复习的详情独立滚动，底部更正与下一字操作始终可见。

## 方案

直接打开详情路由会离开复习上下文；只在下一字时保存会丢失退出前的答案。因此在原页展示详情、立即保存答案，并保留本次作答前的排期快照。更正基于快照重新计算，覆盖同一条学习事件，复习总次数保持一次。认识和不认识都可更正。

本次快照只在当前详情存续期间有效；下一字、切换范围或刷新结束此次更正机会。隐藏并恢复关卡复习页保留当前详情。更正不得覆盖之后新产生的作答；已有筛选、游标和提前复习行为保留。

不升级依赖、不修改数据库结构、不改变正式学习进度。验证包括数据层更正与过期保护、两个入口的答后详情、更正、下一字、各范围游标恢复和 320/390/768/1440px 视口。
