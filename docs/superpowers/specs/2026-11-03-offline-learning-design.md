# 字体学习：离线学习闭环与剩余模块设计

日期：2026-11-03。状态：设计稿 v2，按用户“现有模块 UI 不变”要求修订，待审阅。关联：[功能审计](../../reviews/2026-11-03-function-audit.md)。

## 1. 目标与已确定事项

把现有字体辨识应用完善为可长期使用的个人学习工具：设置学习目标→学习与练习→复习和错题巩固→阅读应用→收藏整理→查看真实记录→备份恢复。每个模块交付完整任务流程，不以单个静态页面、虚假数据或“开发中”提示充数。

用户明确要求：先分析与设计；现有未完成/不能用的功能一并完善；功能编码前新建分支；自行编写、测试并提交。用户已选择**首期离线个人学习闭环**。分支为 `codex/offline-learning-completion`；主干初始版本 `ad547a4`。

沿用 Vue 3/TypeScript、uni-app、Pinia、Vant、现有主题和数据库；H5 与 Android App-vue。维持“学习 / 关卡学习 / 对照阅读 / 我”四个主入口，已有 URL 保留兼容。

首期不建设账号服务端、跨设备云同步、社区、排行榜、付费系统；不引入在线 AI、OCR、语音评分或无来源的字典内容。账号占位入口保留现有名称和外观，进入真实的本机使用/账号状态说明，不假装已经有在线身份。

### 1.1 用户补充的 UI 边界（优先级最高）

**现有功能模块的 UI 完全保留，只完善原功能和修复问题；只为尚不存在的功能绘制、实现新界面。** 这覆盖首页、计划/字体管理、学习预览、答题、文字详情、字形比较、关卡四布局、关卡复习、书架/阅读器、个人中心、资料和设置等已有页面。

- 不改既有布局、颜色、字号、间距、卡片/按钮/导航样式；不为新模块在旧页面加统计区、工具栏、菜单项或新 tab；不重画已有页面。
- 既有占位菜单、消息图标等只接入对应的新页面，保留入口位置和名称。已有可用按钮保持当前流程；不会把“关卡复习”改为先去新总览，也不把现有完成页替换成新报告。
- 真实数值、动态日期、无响应按钮、加载/保存/返回/错误处理是功能修复，可在原有显示位置修正内容；不能借修复调整视觉设计。
- 新页面通过现有占位入口及新模块自己的导航互相连接。对现有组件做必要内部拆分时，DOM 层级/样式与交互结果应保持一致，截图回归验证。
- 既有“长辈版”等显示开关仅修复其用户主动启用后的原定作用；默认显示不变。需要额外的新视觉调整时另行提出，不能默认纳入本轮。
- 草图只包含新增页面。既有首页、单字详情、答题、关卡和阅读器以文字标注复用，不提供替代 UI。

## 2. 路线比较

| 路线 | 优点 | 代价 | 决定 |
| --- | --- | --- | --- |
| 完善离线个人学习闭环 | 复用现有数据库、字体与阅读能力；无网可用；可分模块验收 | 文件备份由用户保管，通知受平台能力约束 | **用户已选择** |
| 同时引入账号和云同步 | 跨设备、换机方便 | 需要服务端、身份验证、冲突合并、在线/离线一致性 | 后续独立阶段 |
| 同时建设社区和内容平台 | 共享和协作 | 额外需要内容授权、审核、运营和反滥用 | 不纳入本轮 |

以下细节是根据现有代码提出的设计选择，尚非用户对每项细节的单独确认。实施不另换框架、不改已有 UI、不删除已有学习/复习规则；若下文有可被理解为改旧 UI 的表述，一律按 1.1 的边界执行。

## 3. 信息架构与页面原则

```text
既有可用页面（保留 UI 与导航）
├─ 首页 → 原计划 / 预览 → 原答题/详情 → 原完成界面
├─ 关卡四布局 → 原关卡预览 → 原训练/完成界面
├─ 关卡复习 → 原学习字形 + 认识/不认识
├─ 对照阅读书架 → 原阅读器 / 原导入流程
└─ 主题、字体、资料、字形比较等现有页面
由既有占位入口承接的新增模块
├─ 我的学习 → 总览 → 课程说明 / 会话报告 / 周月回顾
│  └─ 复习中心 → 错题本 / 专项配置 → 复用原题卡 → 新报告
├─ 我的日历 → 月历 → 当日明细 → 会话报告
├─ 我的词汇量 → 识字概况 → 测评 → 结果/历史
├─ 我的收藏 → 收藏字 / 自定义字单 / 斩字管理 → 专项配置
├─ 我的图书 → 新图书管理/详情 → 复用原阅读器
│  └─ 新导入中心 / 书签 / 摘录工作台 / 笔记 → 原文定位
├─ 消息图标 → 消息中心 → 消息详情
├─ 学习提醒 → 提醒列表 → 编辑 / 权限与平台能力
├─ 学习设置 → 原页面没有的课程范围/复习目标配置
└─ 数据与隐私 / 帮助反馈 / 关于 → 新的完整管理与说明页
已有页面中尚缺失的内容（不重画已可用部分）
├─ 搜索现有词语/句子/文章 tab → 新结果 / 词语或上下文详情
└─ 原头像 / 扫一扫按钮 → 新选择预览 / 本地资料码导入预览
```

这是一张能力关系图，不是改造现有主页面的方案。已有阅读、答题、详情、导航仍复用原页面。新增页面按任务拆分：列表到详情保持返回位置；少量确认和单字段编辑使用底部面板，不为凑数量创建空页面。新增页面具备加载、空数据、无匹配、失败重试、保存中、成功状态。

## 4. 模块设计

### M01 今日学习与学习计划（完善）

**页面与展示**

1. **今日学习（复用）**：原页面结构与外观完全保持，仅接通新学/复习/时长的真实统计及已有消息图标；不增加继续任务卡片或复习入口。
2. **计划设置（复用）**：原滚轮、字体信息、题型选择与保存按钮不改；修复写死日期、剩余天数和保存生效逻辑。课程范围、复习目标等原页面没有的配置放入“设置→学习设置”的新增页面，不在原计划页插控件。
3. **字单预览（复用）**：原 UI、逐字揭示、收藏、斩字、详情等保留；只修复已有交互、数据和继续逻辑，不增加展示区块。
4. **学习会话（复用）**：延用现有三种题型、反馈和结束界面；后台保存与继续完善，不因打开详情把本题判为答对。
5. **会话报告（新增）**：通过“我的学习→记录→详情”查看本轮新学、作答、正确/错误、有效时长和薄弱字；新模块内可继续专项。现有会话的原完成界面和返回行为不替换、不自动拦截。

**规则**：新建计划默认选择一级完整 3500 字；老用户继续原 204 字范围，页面提供明确切换入口。已生成当日字单不因改计划被替换，范围/数量修改次日生效；练习模式修改也只影响后续新会话。单字的首次正式完成是持久事实，不因以后增加题型而变回“未学”；新增题型作为补充练习，保留原完成日期。估计完成日期基于当前剩余字数和每日额度计算，所有字已学完时显示“本范围已完成”。

**数据**：版本化 `LearningPlan`（范围、每日目标、题型、生效日），`learning_sessions` 与固定 `session_items`；复用长期单字进度。收藏、斩字不会删除历史。

**验收**：204 字学完仍可切到完整一级继续；半途退出重启回到同题；更改计划不改变当天已答记录；跨午夜正确分日；结果与首页数据一致。

### M02 课程与关卡（完善并补内容）

**页面**：已有课程分类/关卡目录/预览/训练/完成页外观及流程全部复用。新增课程说明和训练历史详情放在“我的学习→课程/记录”中，不在原关卡页加入口；已有四种布局、最近选择、旧关卡 ID 和已完成轮次保留。

**课程内容**：一级保持现有 3500 字及 351 关结构；补齐二级 3000 字和三级 1605 字，按每关 10 字形成 300/161 关。现有二三级占位 ID 能对应的转为正式关，先校验不存在真实成员或学习数据，再追加其余关卡。不得改一级旧末关和字序。

“偏旁部首”的入口名称、目录和已有成员保持不变。在新增课程说明中解释目前是部首代表字识形范围；新增部首详情、同部首字列表与按组练习放在新模块，不通过重命名旧 tab 或改旧卡片来实现，也不宣称已有完整部首书写课程。

**数据来源门槛**：字表成员/顺序与教育部公布范围核对；拼音、笔画、释义使用有可分发许可的数据，记录 URL、版本、许可和生成脚本。缺少说文、六书和古文字形时显示“未收录”。补齐课程不是只去掉 `placeholder` 标记；每字至少有可用的现代字形、读音/基本释义来源及三题型出题条件。数据缺失和字体缺字单独列出，不能静默显示成错误字形。

**结果与历史**：每轮有开始/结束时间、题型、耗时、错误字与完成状态；重新训练保存独立进度，不重置长期记录。全斩关卡仍禁用训练，不伪算通关。

**验收**：二三级最后一关可进入并完成；升级后一级原记录不变；一轮完整完成只累计一次；中断继续不新建轮次；支持大字库分页、空分类和资源错误。

### M03 复习中心、错题本与专项训练（新增入口并整合）

**页面**

1. **复习中心**：到期数量、最早到期、今日完成、未来排期；入口为关卡复习、每日课程复习、错题与自选专项。
2. **到期复习（复用）**：现有关卡复习 URL、进入方式、仅关卡已学来源范围及“学习字体 + 认识/不认识”的界面完全保持。新复习中心在“我的学习”中进入，可查看跨来源总览；原入口不强制绕到总览，结束也不插入新结果页。报告从新记录模块查看。
3. **错题本**：按来源/模式/时间/错误次数筛选，显示字形、错误类型和最后错误时间；支持批量选字、查看详情、开始专项。
4. **专项配置**：选择收藏/错题/字单/课程、题型与数量；预览实际可练范围；未找到合格字时解释原因。
5. **专项答题与结果**：专项配置和结果是新增页面；答题复用既有题卡、反馈和原有视觉，不另画替代答题界面。补独立会话、断点及薄弱项回顾。

**规则**：沿用现有关卡间隔策略和游标；日常学习增加来源标记，但**每字只有一个正式排期**。同字来自关卡和日常课程时保存来源集合，一次正式回答推进该字唯一排期，所有来源入口立即反映变化，不重复推进或重复统计。已有 `level_review` 的排期原样迁移；新增来源不重置已有时间或阶段。日常课程首次真实作答后建立排期，纯预览不建立；现有关卡答题、详情和斩字触发方式保持兼容。

临时专项默认不改排期、不为未学字创建正式排期；记录本轮作答与错误、有效时长，推动错题巩固，但**不直接写入正式学习题型完成、首次已学、今日新学或首页复习目标**。专项中要正式学习未学字时，显式进入“加入学习”流程，由后续正式学习会话判定完成。“提前复习”是正式复习而非临时专项，沿用当前排期规则。错题解决标准为该字对应模式连续两次独立正确作答，保留历史；用户可恢复到待巩固，不清零累计错误。

**数据**：正式排期以 `characterId` 唯一；来源关系另存，允许对现有 `level_review` 作兼容扩展或一次迁移至统一表。新增 `answer_events`、`mistake_items` 和 `practice_sessions`。表名和细分交由实施规划确定，但不得创建按来源各自推进的主排期。

**验收**：关卡复习更新首页今日复习；多入口同字去重；快速连点不重复写入；刷新后继续；全部/斩字/收藏仍各自恢复；历史只知错误累计时标记“历史累计”，不伪造逐题列表。

### M04 我的收藏、自定义字单与斩字管理（新增）

**页面**：收藏总览→收藏字列表/字单列表/斩字列表→字单详情→创建编辑→选字管理→专项配置→训练结果。三个列表是不同状态的子视图，可共用列表页，不要求每个 tab 再开重复路由。

**展示**：列表每行含学习/对照字形、拼音、状态、收藏时间或来源；按汉字/拼音搜索，按等级、是否已学、是否到期筛选，可切换排序。详情显示字单说明、成员、进度、继续训练和管理按钮。

**交互**：支持建字单、重命名、说明、批量添加/移除、去重、导入汉字文本、导出 UTF-8 文本、删除确认。收藏与字单成员分开：取消收藏不删除自定义字单或学习进度；删除字单只删除组织关系。斩字可单个或批量恢复；恢复参与学习不抹掉历史。

**数据**：复用 `character_progress.favorite/excluded`；新增 `collections` 与 `collection_items`。字单名 trim 后 1–30 字，单字在同一字单唯一；首期字单只收已收录单字，词语/句子收藏另记类型，不拿单字 ID 冒充。

**验收**：从字详情收藏后立刻可查；列表筛选无结果和零收藏可区分；批量移除可取消；汉字组导入反馈已添加/重复/未收录；重启及备份恢复保持成员顺序。

### M05 我的学习、日历与识字概况（新增）

**页面**：学习总览→日历→当日记录→周/月回顾；识字概况→测评说明/范围→测评→结果与历史→薄弱字专项。

**展示**：总览显示去重已学字、各级覆盖、复习作答次数、有效学习时长、当前/最长连续天数；7/30 天趋势可查看对应日期。日历有月切换、今日定位、学习/阅读状态与当天明细。周/月回顾说明范围和比较周期，没有历史时不给虚假增幅。

保留现有“我的词汇量”菜单名称和样式；其原本不存在的目标页展示**识字概况**，解释统计的是汉字学习覆盖与样本测评，而非实际语言词汇量。默认报告已学、已斩、复习稳定字数及收录范围。范围测评默认 30 字，从所选已收录课程分层抽样并固定本轮题单；结果只报告样本正确率和样本薄弱字，不外推未经验证的“全国识字量”。测评复用已有题卡外观，不改学习完成状态和正式排期，可将薄弱字加入字单。

**口径**：学习日为当天至少发生一次有效学习/复习作答，或至少累计 60 秒前台有效阅读。正确率=正确首次提交题数/首次提交题数；重试次数单列。跨模式已学按字去重；连续天数截止今天或昨天；空白历史标为“无记录”。时长内部按秒，展示向下取整为分钟。

**数据**：以事件与会话为事实来源、按日期派生汇总；现有每日记录迁移保留真实可知字段。新统计不回填不存在的历史细节。测评独立 `assessment_sessions/items`。

**验收**：每日练习、关卡、复习和阅读的数字可追溯；跨月/闰日/午夜正确；修改设备时间不产生负时长；旧数据缺失有解释；测评退出继续且同轮字单不变。

### M06 全局检索与字词资料（完善）

**页面**：原搜索页 UI、单字结果、历史、比较篮和文字详情完全保留，只实现原本未开放的“词语/句子/文章”tab 内容及它们缺失的详情/上下文页面。单字既有流程不重画。

**四类结果的数据合同**

- **单字**：当前/新增课程字库，保留原查询与每批 50 条分页方式；不往现有搜索页添加新的筛选栏。部首/等级检索放在新增课程或字单选字页面。
- **词语**：从现有 `character_words` 建去重词索引，含相关单字和可核查出处；只对确有来源的词显示释义/读音，不能拼接单字释义当词义。无词典释义时仍可查看组成字与书中语境。
- **句子**：在已入库且可提取文字的书籍中按原文句界检索，返回原句、书名、上下文与字符偏移；书籍/时间范围可筛选。
- **文章**：检索书籍名称及正文命中片段，返回图书/章节与位置；没有内容时引导导入，不展示伪造联网结果。

从文字详情的常用词进入词语详情。结果可收藏、加入字单（单字）或摘录（句子）；只有单字进入现有字形比较。全文索引在导入/内容变化后分批构建，可取消、查看进度、失败重建；未完成时不把“尚未检索”显示为“0 命中”。

**验收**：快速更换输入不出现旧结果覆盖；连续页不重复；离线可用；未提取的 PDF 清楚说明；原文跳转与书签共用稳定偏移；私人导入内容只在本机检索。

### M07 我的图书、阅读器与笔记（完善）

**页面**：原“对照阅读”书架和阅读器 UI、菜单、手势及进入方式全部保留。个人中心原占位的“我的图书”打开新增图书管理页→图书详情→复用原阅读器；从新管理页进入导入中心、书签/摘录和笔记编辑。新旧入口共享同一套书籍/进度数据，不复制存储。

**新增图书管理页**：最近阅读、阅读中/未读/已读、内置/本地来源、文件类型、名称搜索、排序与管理；列表不加载所有正文。这些新控件不插入原书架。新详情页有名称编辑（本地书）、字数、格式、导入时间、真实阅读位置、书签/笔记入口和删除说明。

**阅读器（仅完善）**：原字体对照、自动翻页、夜间、隐藏/逐步展示、目录、电量、手势和按偏移恢复全部保持，不加菜单项或选字模式。新增图书详情可根据已有阅读位置添加书签，进入独立“摘录工作台”选择原文并写笔记/标签；工作台可查字，保存原文与书名。书签/摘录点击后将字符偏移传给原阅读器，读取该参数不改变阅读器 UI。

**导入**：TXT 编码识别/手选、PDF 文字提取、重名提示、按正文指纹提示重复、进度/取消/重试；扫描或加密 PDF 明确解释需先处理。首期不承诺 OCR。正文版本不变时笔记按偏移+原文摘要定位；重新导入内容变化后不能匹配时提示“原文已变化”，允许查找定位。

**数据**：复用 books/chunks/progress；新增书籍状态/指纹、bookmarks、annotations、reading_sessions 与全文索引。删除本地书前列出关联书签和笔记，允许先导出；确认后事务删除所有关联，不留下幽灵结果。内置书可隐藏，不删随包资源。

**验收**：重排版仍定位原内容；返回查字前页面位置不变；笔记可编辑和导出；导入取消无半本书残留；删除后搜索、最近阅读及批注同步；大文件有明确大小限制和失败反馈。

### M08 字体、显示与无障碍（完善）

**页面**：现有字体管理、字体目录、主题选择界面全部复用。新增资源状态/缺失字体详情放在“数据与隐私→本地资源”中；不替换原管理页，不新增一套字体选择界面。

复用现有字体与主题，不新增 UI/CSS 体系。新资源详情显示样字、当前角色、文件来源、授权说明（已有信息）、加载状态和缺字说明；原导入流程只补校验、持久化、失败恢复和重复检测，重命名等新增管理动作放在资源详情页。移除正在使用的字体使用原选择能力确定回退字体，学习与对照字体不能出现不可恢复空值。

“长辈版”保留既有开关和外观，只修复其已声明功能；仅在用户主动启用后应用对应的字号/可读性行为，默认样式不变。不借此统一重设所有页面的字号、行高和触控布局；超出已有功能定义的视觉调整不纳入本轮。新页面沿用现有主题 token，至少验证浅色、深色和一种其他既有主题。

**备份边界**：数据备份保留字体元信息/引用，不承诺已包含字体二进制。恢复缺少自定义字体时显示缺失清单、引导重新导入并暂用回退字体；不能显示“全部恢复”而实际丢失字体。完整资源包为后续能力，不扩大本轮依赖。

**验收**：刷新和重启保持偏好；字体加载失败可读；320/390/430px 与 200% 缩放可操作；对比表横向滚动限于表格；按钮可用键盘且有可见焦点；减少动效生效。

### M09 消息与学习提醒（新增）

**页面**：消息中心→消息详情；提醒列表→创建/编辑提醒→系统能力与权限说明→测试提醒。

消息仅来自真实本地事件：学习计划、备份结果、资源错误与用户开启的学习提醒，支持未读/已读、单条删除、清空确认、跳转相关页。无消息有明确空状态，首页图标不再空转。

提醒支持时间、星期、开关、提醒内容和本机勿扰时段；学习目标已完成可选择当天不再提醒。更改/关闭应撤销旧排程，避免重复消息。提醒配置与发送历史独立，恢复备份后先不自动请求系统权限。

**平台边界**：H5 首期提供应用内提醒和导出日历提醒文件，后台关闭后不承诺唤醒。Android 先用原生能力验证离线本地通知的排程、取消、权限拒绝和重启行为；既有 manifest 未包含 Push，不能仅调用一个不存在的 API。是否使用官方原生模块由实现前小型验证确定；不为本地提醒接入联网推送 SDK。无法可靠排程时 UI 明示“仅应用内提醒”，不得把定时器当系统通知。系统提醒是独立平台验收项，失败不能标记完成。

**验收**：前台、后台、通知拒绝、改时、关闭、跨日、设备重启逐项验证；H5 在不支持通知时仍能管理计划与导出日历；测试按钮反映实际结果。

### M10 个人资料与本机设置（完善）

**页面**：我→个人资料→字段编辑/头像选择预览；设置→学习设置/显示设置/本机档案信息。复用当前地区选择与编辑表单。

累计学习、坚持天数在原位置接 M05 的真实数据；固定 ID 和虚构 IP 属地作为数据问题修复：保留现有行结构，ID 显示真实本机标识，IP 无实际数据时显示“未获取”，原说明按钮解释离线范围，不移除或重新排版行。头像保持原位置和容器样式，点击进入原先缺失的选择/预览界面；支持本地图片选择、压缩、保存与重置。H5/App 分别处理持久化，大小/格式非法时反馈，不网络上传；备份默认纳入压缩后小头像。

“账号管理”“退出登录”“扫一扫”入口名称、位置和外观均不改。账号管理进入新增使用状态页，明确当前为离线单档案；没有在线会话时点击退出如实说明当前无登录状态，不执行清数据、不虚构退出成功。账号和云同步仍属用户选择的后续范围。

“扫一扫”完善为本地资料码识别与导入预览：只接受本应用字单格式或可校验汉字文本，显示将导入的字、重复项、未收录项，再由用户保存到字单；不自动跳转任意 URL。App 验证 uni-app 扫码原生模块与权限；H5 按能力检测提供相机/图片识别，无法调用时进入同一新导入页的图片/文本备选流程并如实说明，不改旧入口。是否需要轻量解析依赖在实施计划核查现有依赖后决定。

学习设置统一题型、默认课程、复习目标和空闲计时说明，避免和计划页保存两份冲突值。清除学习记录属于 M11 的有范围确认操作。

**验收**：个人资料编辑后所有入口一致；取消头像不覆盖原图；删除头像文件有回退；没有静态账号/IP/累计数字冒充真实状态。

### M11 数据、隐私、缓存与帮助（完善）

**页面**：数据总览→备份导出→恢复预览→恢复结果；缓存明细→清理确认；隐私说明→个人信息/第三方清单；帮助分类→文章；反馈编辑→本地反馈记录/导出；关于→版本/许可。

**备份**：原设置页备份面板、按钮和现有确认流程不重画，完善其底层导出/校验/事务恢复并补入新增表；新增“数据与隐私”页内再提供完整恢复预览/结果页，显示版本、时间、字/书/笔记/字单数量、字体缺失与替换范围。两入口共享服务，兼容旧备份，失败不改变现有数据，保留恢复前快照并提供恢复入口。新数据页的 App 导出提供保存路径、复制及支持时的系统打开/分享入口，说明需另存到应用外。

**缓存**：区分可重建分页/检索缓存与学习记录/上传正文/字体原文件；默认只清理可再生成的数据。删除书籍、字体、重置学习、清空全部本机数据各有独立范围及确认；不能用 `clearStorage` 或删库冒充清缓存。

**隐私/关于**：基于实际依赖、manifest 与运行数据路径编写；显示本机存储内容、权限用途、可导出/删除的范围、第三方库许可。不能写“绝不联网”而不核查资源请求，也不虚构运营主体或客服渠道。帮助至少覆盖学习/斩字/复习、字体缺字、TXT/PDF、备份换机和数据失败恢复。

**反馈**：离线保存问题描述、页面、版本和用户自选的诊断信息；导出文本/JSON，复制内容方便用户自行联系维护者。没有真实收件地址/服务端时不得提示“已发送”。默认不附书籍正文、个人资料或完整备份。

**验收**：备份往返覆盖全部新增数据；错误格式/未来版本/损坏关联均阻止恢复；清理缓存后学习与笔记仍在；帮助文章可读且返回正确；反馈离线可保存和导出。

## 5. 统一的数据与行为合同

### 5.1 学习事实与计时

- 首页“今日新学”按当日本地日首次正式完成的单字去重，涵盖日常和关卡；超过每日目标时展示实际值及超额量，不截断。每日字单的“本任务进度”另按固定成员计算，不因为其他关卡学过别的字而替换当日字单。
- 首页“已复习”按正式复习有效提交次数计，认识/不认识均为一次，单位明确为“次”；同字多次合法复习可多次计数。临时专项与测评不计入此目标；专项在学习明细单列，测评时长与成绩单列。
- 长期“已学”以首次正式完成事实判断。老数据优先使用已有 `completedAt`/明确 completed 状态；只有题型完成证据时按迁移前生效模式一次判定并标记来源，不编造未知完成时间。后续全局题型改变不追溯改写此事实。
- 新增不可重复提交的作答事件 ID、会话 ID；记录实际发生时间、来源、字、题型、答案结果和本轮序号。快速连点、重试提交和恢复页面不能复制事件。
- 时间戳保存 UTC ISO 字符串；另保存发生时本地日期与时区偏移。历史日期按当时本地日归属，改变时区不重写旧日历。
- 计时用单调时间差，前台且有交互才累计；学习页 2 分钟无交互暂停；阅读可在前台按翻页/揭示/滚动恢复，后台立即暂停。同一时刻只允许一个活动会话计时。
- 跨午夜拆分时长和事件，不把旧日全部状态重存到新日；系统时钟回拨不产生负数或巨额时长。
- 旧 daily_sessions 学习时长可作为历史来源；新事件上线后不再与已包含它们的旧汇总重复相加。

### 5.2 持久化、迁移与备份

- 从 DB v2 顺序升级；每次新增 schema 都为 SQLite 与 IndexedDB 实现对应版本迁移，不能只改列定义。批次编号和最终版本在实施计划按实际拆分确定。
- 保留原角色字体、主题、字 ID、关卡 ID、个人资料、收藏、斩字、复习时间和阅读偏移。内容升级只改内容表。
- 新增模型按职责归入课程/计划、学习事件与会话、字单、批注、提醒/消息、测评；不把全部业务数据塞进 settings JSON。
- 旧备份缺少新增表按空表处理，新增派生数据可重建；新格式有明确版本和引用校验。恢复以事务完成，再刷新 store 与页面缓存。
- 用户输入均作长度、类型和引用验证；书籍与笔记显示文本，不使用不受控 `v-html`。

### 5.3 页面与代码边界

- uni-app 页面注册在 `pages.json`，路由参数使用稳定 ID，直接进入或系统返回有合理兜底。
- 按独立交互拆分现有阅读/学习大组件；非 DOM 计算进入纯函数，响应式共享逻辑进入 composable；不为行数机械搬迁所有代码。
- 使用具名类型、props/emits、纯 computed；业务错误可恢复并提供反馈，所有定时器、监听和资源 URL 均清理。
- H5 DOM 与 App 原生 API 均有平台边界；不把 Vant 的 WebView 可用性扩展成小程序兼容承诺。
- 列表分页/分段，书架只查元信息，全文搜索分批构建；不一次渲染 8105 字或所有书籍正文。

### 5.4 离线启动范围

- Android 的应用壳、当前内置字库、字体和 PDF 解析器随包提供，首次使用无需服务器；导入的可读正文持久化到数据库。
- H5 不仅要求已打开页面断网后可继续，也要求**首次在线准备完成后，在支持 Service Worker 的 HTTPS/localhost 环境断网刷新、关闭再打开仍能启动**。未完成离线准备时显示资源清单和状态，不能提前标记“离线可用”。局域网普通 HTTP 不支持同等保证，页面明确说明。
- 复用 Vite 构建能力生成缓存清单，首批原子缓存应用壳、字库、当前两种字体和必需解析资源；其余大字体/内置书籍按需缓存并显示是否就绪。不预缓存所有潜在的大文件，不引入新的 UI 或服务端依赖。
- 缓存按应用内容版本管理，新版本必需资源全部准备好后才提示更新；当前会话中不强制替换。可重建资源缓存与用户数据库严格分离；缓存空间不足时保留旧可用版本并反馈，浏览器清除站点数据仍会影响本地数据。
- 用生产 H5 验证“在线准备→断网→刷新→重开→学习/阅读本地已准备内容”，开发服务通过不算离线启动验收。未缓存书籍或未导入正文的资源显示不可用原因，不伪装成空书。

## 7. 分阶段交付顺序

这是设计层的依赖顺序；设计确认后再写逐文件、逐测试的实施计划。

1. **基础与已有缺陷**：确认测试运行时差异；补会话/事件/计时与迁移合同；接通复习计数，修固定日期、假累计和资料身份；验证旧数据不丢。
2. **个人学习闭环**：M01、M03、M04、M05；收藏可管理、错题可练、结果可追溯、日历可查看。
3. **内容与课程**：M02、M06；课程数据与许可核验在本阶段开头完成，先保证二三级真实可学，再开放搜索与测评范围。
4. **阅读应用**：M07；图书入口、导入管理、书签/摘录/笔记、查字联动与全文检索。
5. **配套模块**：M08–M11；提醒平台验证可提前做以降低风险，最终补齐无障碍、资料、设置、备份、帮助和许可。
6. **整体验收**：新装/老用户升级、跨日、离线、刷新重启、失败恢复、手机视口与 Android 真机清单。

每个阶段按完整流程形成可审核提交，例如 `fix: ...`、`feat: ...`、`test: ...`；每个提交包含相应代码、测试和必要文档，不积压为一个巨型提交。只暂存本任务文件，默认不推送远端、不合并主干。

| 视觉与可访问性 | 新页验证 320/390/430px、深浅主题、200% 缩放、键盘焦点和安全区；旧页同状态前后截图对比，默认 UI 无变化；真实数值/日期的动态差异单独核对 |
| Android 真机 | SQLite 首次导入/升级/后台保存、文件导入/导出、字体/头像持久化、PDF、返回栈、通知权限与排程；构建成功不能替代 |

模块验收必须同时满足：有真实数据与可完成动作；有前后关联页面或合理面板；有空态/错误态；退出刷新能恢复；相关自动化通过；新增数据能备份；文档写明实际验证与未验证内容。

修复 bug 优先用失败测试复现，不删断言或空 catch 掩盖问题。旧样式、布局、滚动行为和导航外观均为保护对象，不通过修改它们迎合过期断言；只有确认用例相对本次开发前的真实 UI 已过期，才更新该用例并保留功能等价断言。新功能或实际数值变化对应的测试准确同步，不能把基线失败全部当作需重写的测试。

## 9. 待审阅与实施者可决定事项

- 需要用户确认：新增模块方案及开发顺序。旧模块 UI 不改已由用户明确要求，无需再询问。
- 实施者决定：具体组件和 composable 划分、路由命名、新增索引/分词粒度、分批大小及迁移版本拆分，前提是不改变以上功能合同。
- 能力验证决定：Android 本地提醒实现方式、当前 Node SQLite 的特殊文本测试支持边界；证据不足时如实列为平台限制，不标记完成。
- 字库来源核验失败不能用假内容顶替；已收录课程与字典功能可独立继续开发，二三级课程保留明确未完成状态直至数据验收。
