# 四种关卡布局与偏好设置

用户已认可当前布局和三种手机方案。本轮将四者全部接入原有 Vue 3 / uni-app / Pinia / SCSS 项目，默认保留当前布局，不再选择或重抽设计方向。

## 结果

“我 → 关卡布局”和“个人设置 → 关卡布局”打开同一选择页。四个选项为经典卡片（当前默认）、手帐字帖、口袋闪卡、闯关棋盘。选项包含布局缩略图、名称、说明及明确的已选择状态，支持触控和键盘。选择立即保存，并在应用初始化与数据恢复后重新读取。

原先的模板感来自关号、十个小字格、进度和操作反复等权出现。用户认可保留这些选择，因此本轮的重点是提供不同的阅读与选关方式，而不是替换默认页：字帖以字形为主，闪卡以单关为主，棋盘以选关为主。

## 内容和业务边界

- 一级汉字共 256 关，保留真实字表、顺序和末关的实际字数。
- 保留偏旁部首、一级、二级、三级分类。
- 保留二级、三级的待上线状态和原有提示。
- 原有 24 关分批加载、继续加载、错误重试和空状态不变。
- 闪卡逐关切换、棋盘每组 12 关，跨越首批数据时等待后续批次。
- 完成数、部分学习进度、继续学习和复习操作来自同一状态层。
- 所有开始按钮进入原有 level-study 页面。
- 主题始终来自页面根节点的 themeStyle，包括五套配色与深色模式。
- 设置保存在既有数据库 settings 表，不新增数据库架构或依赖。
- 字帖字体优先本机楷体，无楷体时使用项目现有简体宋体，保持简体字形。
- 选择页缩略图用于辨认布局，装饰内容从辅助技术中隐藏；完整名称和说明另行呈现。
- 布局和配色相互独立，切换不重置学习记录。

## 实现边界

复用上轮 A / B / C 的方向：Editorial greeting（1163171170）、Pastel consumer（44479611）、Accent ladder（1734476856），保留 palette/type。没有新图片、外部字体或界面框架。

原 levels 页面超过 300 行；多布局接入后，将数据库加载、学习进度推导和导航提取至 useLevelStages。各布局拥有独立视觉组件，闪卡和棋盘共用 useStagePager。设置使用独立 Pinia store，原经典卡片组件保持不变。

## 测量说明与看图结论

保留的提示：字帖目录大量的进度副信息为 12px，楷体的全宽汉字被测量器归类为 mono；320px 棋盘的次要信息为 12px；桌面经典卡片的完整目录需要滚动。这些均与实际用途相符。选择页装饰缩略图中的文字不作为正文尺寸衡量，正文名称、说明和选择状态正常检查。

源码 lint 为 0 FAIL、2 WARN：零填充是实际关号；shadow 提示命中的是既有 `box-shadow: none`，没有新增静态阴影。

字帖形成大字与目录的节奏，桌面采用并列两栏；闪卡保持聚焦，翻关和快速选择承担次要操作；棋盘保留高密度选关，固定预览区让开始操作保持稳定。选择页以缩略图说明差异，不新增学习数据。相较初稿，手机 320px 下字帖和闪卡的主操作已完整露出。
