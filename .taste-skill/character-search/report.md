# 统一文字搜索与多字字形比较

沿用现有 Vue 3、uni-app、Pinia、Vant、SCSS、数据库及用户主题。本轮是既有产品功能扩展，沿用已选的应用设计系统，没有重新抽取视觉方向，没有新增外部图片、字体或依赖。

## 内容与任务

- 学习、四种关卡布局、阅读书库顶部共用文字搜索按钮。
- 阅读器正文顶部和展开的阅读菜单中也可搜索，返回后保留原阅读位置。
- 搜索由原 204 字每日范围扩展到完整 2557 字内置字库。
- 保留单字/拼音检索、分页、详情跳转、搜索记录和原有模式说明。
- 输入连续汉字或带空格、逗号的字组时，逐字精确匹配并按输入顺序展示。
- 搜索结果可以逐字加入比较，也能将整组加入。
- 比较最多 6 字，按 ID 和简体字形去重；支持移除、清空、下次打开恢复。
- 比较表同列对齐展示学习字体、对照字体、拼音、笔画、结构、释义和常用词。
- 所有信息来自既有字库；字体、配色跟随用户的全局设置。
- 比较列表仅保存 ID，不修改学习进度或读取位置。
- 手机上能同时看清 3 个字；更多文字在同一个表内横向滚动，所有行保持对齐。
- 空列表提供真实常见字组“己已巳 / 未末 / 土士 / 日曰”，选字后收起示例，优先展示比较内容。

## 设计与实现

页面首先回答“我要比较哪些字，以及它们哪里不同”。以实际字形作为主要内容，输入、移除和清空位于表格上方，字形按同一字体逐行排列，释义按同一文字逐列排列。没有新增统计卡片或无关装饰。

搜索请求、历史记录和过期请求保护放入 useCharacterSearch，搜索结果独立为组件，避免继续堆大页面文件。新增比较 store 复用 settings 持久化与应用初始化。阅读大文件仅接入共用入口并修正受顶部高度影响的局部布局，没有重构无关阅读流程。

看图后修正：小屏阅读书库保留可见书籍列表；关卡标题说明避免单字换行；比较按钮文字居中；已选文字时收起示例；缩小窄屏比较列以容纳三个字。阅读重排测试还发现轻点正文可能误开菜单，现保持隐藏对照时的揭示意图，分页尚未就绪则不误开菜单。

## 验证

- `pnpm type-check` 通过。
- 相关单元测试 20 项通过：比较解析、去重/上限、持久化、字库完整范围与分页，以及原搜索排序。
- 生产版新搜索/比较与全屏阅读共 28 项通过；原关卡目录 8 项单独复测通过。
- 原首页的搜索模式、详情跳转、历史记录回归另 1 项通过，合计覆盖 37 项页面用例。
- 并行 App 编译和多浏览器检查时，曾有一项关卡首次字库准备超过原有 5 秒断言等待时间；错误快照仍在“正在准备本地数据”，没有数据错误。没有修改该测试的断言或等待时间，8 项关卡回归单独复测全部通过。
- 初版分页测试使用 `shi`，真实字库只有 42 个匹配，已改用有 141 个匹配的“一”验证 50/100 条分页，没有降低分页断言。
- 初次阅读回归暴露的 1280px 重排轻点误开菜单已修复，同一回归用例通过。
- 最终 H5 与 App-vue 构建通过。
- Skill lint：0 FAIL / 2 WARN；提示命中比较表中必要的字体/字义行标签，非装饰性眉题。
- Skill 的原始浏览器 probe / judge：320、390、1440px 均 0 FAIL。正文最小触控目标 44px，无页面级横向溢出；两个字体行的字形列坐标一致。
- 比较需要 UI 字体、学习字体和对照字体，因此保留三个字体角色；大号文字为汉字数据，不按营销标题行数限制衡量。剩余提示是次要元信息字号及桌面输入区留白。
- 已查看手机、桌面、深色截图，五套主题均经过交互检查。

自评：设计 7、易用 8、创意 7、内容 9。主要价值是用户真实字组在真实字体中的对齐比较，整体保持既有产品风格。
